Mode Kelola Foto Ketuk foto mana pun untuk mengganti, menghapus, atau mengubah judulnya.

Edit Foto

Setelah selesai mengedit, jangan lupa klik Simpan ke File di bagian atas agar perubahan tersimpan permanen di file.

Bantuan — Kelola Foto

  1. Cara termudah: tanpa mode ini pun Anda bisa mengganti foto dengan menimpa file di folder foto (nama file sama) lalu refresh browser — panduan lengkap ada di file CARA-GANTI-FOTO.html.
  2. Klik Kelola Foto (tombol kiri bawah) untuk masuk mode edit.
  3. Mengganti foto: ketuk foto yang ingin diganti → pilih Ganti Foto dari Perangkat… → pilih foto baru Anda.
  4. Menambah foto: klik + Tambah Foto di bagian atas, lalu pilih satu atau beberapa foto sekaligus. Foto baru otomatis masuk ke Galeri Lengkap dan galeri berjalan.
  5. Menghapus foto: ketuk fotonya, lalu pilih Hapus Foto Ini.
  6. Mengubah judul / kategori: ketuk fotonya, lalu isi kolom Judul atau Kategori.
  7. Menyimpan permanen: klik Simpan ke File → file rio-satu-file.html akan terunduh: versi website dengan semua foto yang Anda pasang lewat browser ini menyatu jadi satu file, praktis dikirim ke orang lain.
  8. Foto Asli mengembalikan semua foto seperti kondisi awal file.

Foto yang Anda pilih otomatis dipadatkan agar website tetap ringan — dan hasil “Simpan ke File” menjadi satu file yang bisa dibuka di mana saja tanpa internet (foto yang belum diganti lewat browser tetap diambil dari folder foto). Semakin banyak foto ditambahkan, semakin besar ukuran file-nya.
